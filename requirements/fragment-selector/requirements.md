# fragment-selector 要件

## 責務
「焦点イマージュ」と「周辺断片」を選択する。断片選択ロジックの中核。

## 選択ロジック

### 焦点イマージュの選択
- link-graph から「間のリンク」候補（高 gap_score）を優先的に選択
- 直近ページ（14日以内）は確率を下げる（タスク化衝動の抑制）
- 完全除外はしない（差異の反復のため）

### 周辺断片の構成（近傍70% / 跳躍30%）

**近傍探索（70%）：グラフ探索**
- 焦点ページから 1〜3 ホップ以内のイマージュ
- link-graphのBFS/DFS

**跳躍探索（30%）：**
- グラフ上で遠いが弱い繋がりを持つ断片
  - 共有リンク（co-linkエッジ）
  - 同時期編集（タイムスタンプの近接）
- またはagentが外部から持ち込む素材（Phase 2以降）

### 選択の原則
- 最適化しすぎない（ランダム性を保つ）
- ユーザーの状態を推定しない
- 付きすぎず離れすぎず（連歌の付け合い）

## 配合比（自己素材 vs agent素材）
- 約7（Scrapbox由来）対3（agent由来）
- Phase 0〜1は10:0（自己素材のみ）
- Phase 2でagent素材（Spotify、書籍等）を追加

## 入力
- link-graph（グラフ探索用）
- rag-index（「間のリンク」の gap_score 計算用）
- image-segmentation の出力（イマージュ一覧）

## 出力
```
SelectionResult {
    focal_image: ImageUnit      # 焦点イマージュ
    neighbors: list[ImageUnit]  # 近傍断片（5〜10個程度）
    leaps: list[ImageUnit]      # 跳躍断片（2〜3個）
    gap_score: float            # 焦点の「間のリンク」スコア
}
```
