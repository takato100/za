# image-segmentation 要件

## 責務
Scrapboxページを「イマージュ」単位に分節する。
イマージュ = 知覚的に自立した断片（メディア形式ではなく意味的自立性で定義）。

## イマージュの定義
| 種別 | 例 |
|------|-----|
| テキスト断片 | 一語〜数段落（意味的に完結しているもの） |
| 画像単体 | ページ内の画像 |
| テキスト＋画像 | キャプション付き画像 |
| 埋め込みURL | OGP情報を持つリンク |

## 処理フロー
1. ページ本文を構造解析（Scrapboxの記法に基づき行・ブロック分割）
2. LLMで各ブロックの「知覚的自立性」を判定・グルーピング
3. イマージュにメタデータを付与（種別、元ページID、位置）

## LLMへの依存
- 分節の判定にClaude APIを使用
- プロンプト設計が品質の鍵（Phase 0で反復的に調整）
- コスト：ページ数 × 平均トークン数 × 価格。Phase 0は数十ページで検証

## 出力データモデル
```
ImageUnit {
    id: str           # "{page_id}::{index}"
    page_id: str
    type: enum        # text / image / text+image / url
    content: str      # テキスト内容
    media_url: str?   # 画像/URLがある場合
    position: int     # ページ内の順序
}
```

## 品質検証（Phase 0でやること）
- 実際のScrapboxページで分節結果を目視確認
- 「一行ですが意味的に自立している」ケースの検出精度
- 「複数行がセットで一イマージュ」のケースの検出精度
