# web-renderer 要件

## 責務
generation-engineの出力を受け取り、エディトリアルデザインのHTMLページを生成する。
iOSアプリのWKWebViewで表示される。

## デザイン原則
- カード型ではなく「一枚の流れ」
- 余白が呼吸するレイアウト（素材間の距離が意味を持つ）
- 出典インジケータ：薄く存在するが、長押しで詳細表示

## コンテンツタイプ別レイアウト
| タイプ | 表示方法 |
|--------|---------|
| テキスト断片 | 可変幅テキストブロック。font-sizeは重要度で変化 |
| 画像 | フルブリード or インセット（spacing_hintに依存） |
| テキスト＋画像 | テキストが画像に回り込む or 縦積み |
| 埋め込みURL | OGPカード（シンプル版。装飾なし） |
| 音楽（Phase 2） | ミニプレーヤー |

## 出典表示
- 各断片に薄いドット or ラインのインジケータ
- 長押し（iOS）でシート表示：「このページのScrapboxを開く」等
- 主張しないが必ず辿れる

## 技術選定
- **生成：** Claude API で HTML/CSS を直接生成（Phase 0）
  → Phase 1でテンプレートエンジン（Jinja2等）に切り替え検討
- **表示：** WKWebView（iOS）
- **フォント：** システムフォント（SF Pro）を基本とする

## 一回性
- 同じGeneratedPageからは常に同一のHTMLを生成（決定論的）
- 変奏はgeneration-engineレイヤーで行う（web-rendererは変奏しない）
